Comparison

A self-hosted AI coding agent — entirely in your cloud.

"Self-hosted" gets used loosely. The real question is architectural: does the whole system — control plane included — run on infrastructure you own, or does part of it always phone home to someone else's cloud? Here is the honest, sourced breakdown.

Facts verified as of November 2, 2026, from each vendor's own primary sources (linked below). Re-checked immediately before this page ships — vendor terms and tiers change.

Fully in your cloud, or hybrid?

Shipwright's control plane, agent runtime, and your code all run on infrastructure you own, at every tier — no managed-service layer in between. The rest of the field is either hybrid (part of the system stays in the vendor's cloud) or gates full self-hosting behind a sales conversation.

Questions security and compliance teams ask

Can Shipwright run inside our private VPC?

Yes. The admin service, task store, metrics and agent runtime deploy to infrastructure you own, with Docker or the Helm chart on your own Kubernetes cluster. Your repository and the agent's working copy stay there. By default every service is reachable only inside the cluster.

Does any data leave our infrastructure?

Yes, the model calls. Shipwright runs Claude Code, which sends prompts and the code context it needs to Anthropic's API on your own API key or Claude account. Agents also reach the services you connect, such as GitHub and Slack. Nothing goes to Shipwright or App Vitals, because there is no Shipwright-hosted service in the path.

Can several agents run at once, isolated from each other?

Yes. On Kubernetes each agent gets its own Deployment, persistent volume, Secret and scoped token. Self-serve tenant agent pods can be isolated with an opt-in NetworkPolicy (off by default, and enforced only if your CNI supports NetworkPolicy) that allows DNS, the Shipwright services and the public internet. For other agents, egress restriction is your own NetworkPolicy or firewall rules.

Is Shipwright SOC 2 certified?

No, not currently. Shipwright is MIT-licensed software you run, not a hosted service, so it runs under your own controls. A fully egress-locked or air-gapped deployment isn't supported out of the box, because agents need to reach the model API.
