# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Report vulnerabilities through GitHub private security advisories:

1. Go to [https://github.com/app-vitals/agent/security/advisories/new](https://github.com/app-vitals/agent/security/advisories/new)
2. Describe the vulnerability, the steps to reproduce it and its potential impact.
3. A maintainer will acknowledge the report within 7 days and work with you on a fix and coordinated disclosure.
